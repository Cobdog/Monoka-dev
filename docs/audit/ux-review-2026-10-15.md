# The blind adversarial UX review — first launch to chained generations (2026-10-15)

> Commissioned by the maintainer: *"an objective and critical eye starting from first launch, to getting back your first clip, chaining it into the next… Just because something is done a certain way right now does not mean it is the right way."* Post-remediation, pre-planning — the house-in-order pass that displaces the theming round.
>
> **Method:** three blind Opus-class reviewers (no audit history, no remediation narrative, no keep-lists — code read only to verify observed behavior), driving the REAL app from a fresh clone against a REAL fresh ComfyUI 0.41.0 with **live CUDA renders** (maintainer-authorized GPU window). Legs: R1 launch→first-clip (timed end to end), R2 the working loop (clip→chain→references→prompts, gestures accounted), R3 the IA/modularity critic (every surface). Evidence: the three reports + 150+ screenshots in [ux-review-2026-10-15/](ux-review-2026-10-15/) (reports verbatim; the charter in BRIEF.md).
>
> **Synthesis by the controller** — deduplicated, adjudicated into dispositions: **FIX-NOW** (bug cards, some already dispatched), **DESIGN-ROUND** (feeds the wizard rework 3p14abm, the hash catalog to7xpa7, or a new design item), **KEEP** (earned praise, binding).

## The measured story

| Measurement | Value | Source |
|---|---|---|
| Launch → first clip back | **23m34s** (0.6s paint, 3m02s to submit, 20m32s submit→landed incl. crash+retry, 18min sampling) | R1 |
| One loop turn (chained generation) | **~14 gestures + 18min render** (happy path 9–12; the simple version is ~6) | R2, measured |
| "Fast · 4-step" tier, actual | **30 steps, 19.8 min** | R2, engine history |
| A render that outlives its tab | **Silent total loss, even on success** (0 db rows; the mp4 exists only in engine history) | R2, verified twice |
| The shipped loop, one sentence | *"type → Enter → 20 min → pray the tab survives → play once (no scrubbing) → fork from the wrong frame → 20 more minutes"* | R2's verdict |

The connect flow is NOT the problem (3 minutes, honest). The costs are: wrong defaults (the slowest tier inherited silently), broken-by-default execution (the preview crash), dishonest states (queue/progress/failure), a review surface that doesn't exist, and a job-ownership model that loses completed GPU work.
